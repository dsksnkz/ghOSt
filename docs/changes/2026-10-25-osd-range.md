# Forgiving exit range and animated wheel volume

## Behavior

- Inactive activation stays 2px wide along the full left/right edges, with the
  existing 200ms dwell. Opening still captures the pointer height once.
- Once latched, the retention/input strip expands to 72px inward. The popup card
  and an active slider drag also keep it open. Moving away gets 100ms exit grace;
  returning during grace cancels closure without another dwell or reposition.
- The expanded edge window subtracts the 44 × 294px popup-card rectangle from
  its input mask. This preserves the popup's own hover, slider and wheel input
  instead of covering them with a transparent interception surface.
- Wheel over either the retention strip or popup changes volume in 2% steps.
  Existing 0–100 clamping and no-volume-change-on-hover are retained.
- Fill height and displayed percentage interpolate over 120ms OutCubic. Actual
  audio value updates immediately. Dragging stays direct; reduced motion snaps
  values. Existing entrance/exit animation, geometry and theme are unchanged.
- There is no following of the cursor after spawn, idle animation, keepalive
  poll or per-motion subprocess. Fullscreen suppression remains unchanged.

## Implementation

`EdgeHold.qml` adds a cancellable 100ms release timer; it only runs during exit.
`EdgeHandle.qml` expands only while latched, uses a subtractive card input mask,
and includes card hover/interaction in its hold condition. `OsdState.qml` tracks
card hover; release clears it. `Osd.qml` adds a non-grabbing HoverHandler,
wheel-only MouseArea and animated readout property. Intro help describes the
new range and scroll controls. The opt-in native helper allows release grace.

## Verification and limits

including a short exit remaining open, quick reentry cancelling closure with
unchanged spawn Y/activation count, and closure after grace. Existing dwell,
long hold, audio callback, reentry and keyboard expiry cases remain covered.
Pure JS geometry/search/volume checks and production QML compilation pass.

Exact modules deployed with automatic ghOSt reloads and Configuration Loaded
logs. No manual reload command, physical cursor movement, game modification,
real audio adjustment, interactive/full regression suite or screenshots while
the user is gaming. Mask/hover/wheel/animation code compiled, but native physical
input and rendered interpolation have not been end-to-end verified in this pass;
do not represent those as completed visual tests. Existing helper is opt-in and
continues to refuse pointer tests while CS2 runs or the output is fullscreen.
