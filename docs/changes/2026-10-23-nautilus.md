# Nautilus folders and contrast

Reuses the approved `folder-rounded` SVG, including its rounded inner corners.
`scripts/install_nautilus_theme.py` builds a small `ghOSt-Folders` overlay with
17 regular and symbolic folder aliases. Other icons inherit Breeze Dark,
Adwaita and hicolor. Symbolic folders are recolored by GTK for control states.
The icon-theme preference is desktop-wide for GTK apps, not exclusive to Files;
only folder artwork is replaced. No packages, shortcuts or shell changes.

`config/ghost/nautilus.css` scopes neutral dark backgrounds and paired light
foregrounds to Nautilus. The selected accent has a dark foreground. Does not
replace other applications' CSS, fonts, cursor or GTK theme preference.

## Apply and recover

Build only: `python scripts/install_nautilus_theme.py`.
Explicit activation: `python scripts/install_nautilus_theme.py --apply`.
Activation snapshots the affected theme directory, both GTK settings files,
GTK4 import/stylesheet and previous GSettings values before making changes.
This machine's snapshot is under
`~/.local/state/ghost/backups/nautilus-20261023-200700-457782/`.
Its `before.json` maps original paths to saved copies, or null for paths newly
created by this install. Restore those exact files and the recorded GSettings
values to undo; preserve any edits made since activation first.

## Verification

- Two tests check every regular/symbolic alias, inheritance and main palette
  foreground/background contrast above 7:1. This is not a whole-app WCAG claim.
- GTK4 parses the stylesheet without CSS errors; actual icon lookup resolves
  folders, Documents, Downloads and Home symbolic variants to the overlay.
- Actual Nautilus 50.3.1 inspected on an isolated Broadway display: dark sidebar,
  dark main view, readable labels and approved rounded icons. No visible testing
  windows on the user's desktop during this stage.
- Applied preferences, opened native Files and inspected the running desktop:
  correct folder icons, readable filename/sidebar text and selected folder.
  Published image is a cropped native view containing only generic folder names,
  not the user's home contents, device names or other applications.
- Runtime warns about an existing malformed third-party desktop file and an
  unavailable search indexer; neither is changed or claimed fixed by this task.
